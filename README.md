## 🛡️ About

Independent security researcher focused on finding and responsibly disclosing vulnerabilities. Active in bug bounty programs, reverse engineering, and exploit research.

- 🔭 Targeting: web apps, APIs, mobile, and low-hanging 0-days
- 🌱 Sharpening: advanced IDOR, SSRF, auth bypass, binary exploitation
